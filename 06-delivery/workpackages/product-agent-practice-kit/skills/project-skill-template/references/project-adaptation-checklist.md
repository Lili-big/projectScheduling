# 项目Skill适配检查表

## 触发

- 是否描述了用户会如何提出请求，而不是只写Skill名称？
- 是否与已有Skill重叠？若重叠，项目差异是否真实存在？

## 权威来源

- 是否只读取完成任务所需的最少项目文件？
- 文档、代码、测试和用户最新决定冲突时，优先级是否明确？
- 是否避免把单次聊天结论固化为长期规则？

## 工作流

- 核心动作是否可重复执行？
- 高风险步骤是否具有低自由度和明确门禁？
- 是否声明完成条件、停止条件和下一阶段路由？

## 输出与验证

- 输出是否有稳定位置和格式？
- 是否包含错误、空态、兼容和证据边界？
- 是否有聚焦验证命令，并区分全量门禁？

## 安全与共享

- 是否清除了客户原件、账号、密钥和个人绝对路径？
- 是否区分磁盘存在、系统发现和当前会话可用？
- 是否明确全局模板与项目执行副本的升级关系？
