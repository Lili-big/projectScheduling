# 实施

## 前置门禁

1. 在仓库根目录运行一次：

   ```powershell
   .specify/scripts/powershell/check-prerequisites.ps1 -Json -RequireTasks -IncludeTasks
   ```

2. `tasks.md` 缺失，或当前对话没有用户对 `tasks.md` 与一致性结果的明确确认时，立即停止。
3. 读取 `tasks.md`、`spec.md`、`plan.md`、Constitution 和实施所需的最少项目上下文。

## 工作流

1. 按依赖顺序执行已确认任务，保护工作树中的无关修改。
2. 不引入任务之外的功能、重构、兼容层或架构变化。
3. 每完成一个相关批次，运行一次与风险匹配的最小验证。
4. 更新 `tasks.md` 中实际完成的任务状态；不得把未验证任务标为完成。
5. 验证失败时分类：

   - 当前任务相关失败：定位并修复，随后只重跑相关验证。
   - 仓库既有失败：保留证据，不归因于当前修改。
   - 环境失败：说明环境限制和未覆盖风险。

6. 核心目标未满足时不得用非核心测试通过代替完成。
7. 安全、权限、数据完整性、迁移、不可逆操作和外部发布仍需独立确认。

## 完成

只有以下条件同时满足才结束：

- 已确认任务完成或明确记录未完成原因。
- 核心用户故事和验收标准得到验证。
- 相关失败已经修复或有证据表明属于非当前范围。
- 验证命令、结果和残余风险已记录。

向用户报告实际修改、完成任务、验证证据、未完成项和残余风险，然后停止。
