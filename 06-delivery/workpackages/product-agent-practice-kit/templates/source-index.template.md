# 原始资料来源索引

## 使用规则

1. 原件进入 `01-inputs/raw/`，不得在原件上直接修改。
2. 每份资料分配稳定来源ID：`SRC-001`、`SRC-002`……
3. 同名不同内容作为新版本登记，不覆盖旧文件。
4. 登记资料能证明什么、不能证明什么。
5. 敏感资料注明 `local-only`，不得提交或跨项目复制。
