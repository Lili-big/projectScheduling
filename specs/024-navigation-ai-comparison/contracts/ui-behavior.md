# UI 行为契约：导航与 AI 多方案详情

## 导航契约

| 分组 | 子项顺序 |
| --- | --- |
| `1. 项目基本参数` | `1.1 工艺工效库`、`1.2 工艺逻辑`、`1.3 资源配置`、`1.4 任务视图`、`1.5 里程碑` |
| `2. 前期策划` | `2.1 AI多方案比选`、`2.2 模拟求解` |

- 两组首次加载均展开，可独立折叠。
- 一级分组不打开工作区标签。
- 子项打开的工作区标签名称与导航名称一致。
- 整体侧栏折叠不重置分组展开状态。
- `模拟求解-MVP` 不得出现在导航、标签或渲染分支中。

## 方案卡契约

| 条件 | “查看方案详情” |
| --- | --- |
| 无 `plan_result` | 不显示 |
| 有可行或最优结果 | 显示 |
| 有不可行、未知或模型无效结果记录 | 显示，用于查看诊断 |
| 请求异常且未形成结果记录 | 不显示 |
| 修改资源导致结果失效 | 立即不显示 |

## 详情态契约

进入详情后必须显示：

- 返回多方案比选；
- 方案名称、经济/平衡/抢工档位和求解状态；
- 当前方案对应的完整结果内容和诊断。

进入详情后必须隐藏：

- 三方案卡和资源数量编辑；
- 核心指标对比和推荐区域；
- 模拟参数及所有求解按钮；
- 保存结果和历史方案对比操作。

返回动作只改变本地视图状态，不得调用初始化、求解、指标对比或推荐接口。

## 数据一致性契约

- 结果内容只能读取当前下钻方案的 `ResourceAssistantPlanResult`。
- 资源展示必须读取当前下钻方案的 `resource_pools`。
- 不得读取完整模拟求解页面的全局 `solveResult` 作为 AI 方案详情。
- 场景变化或资源数量变化后，不得继续展示旧详情。

## 公共接口影响

无。现有 `/api/ai-resource-assistant/*` 和 `/api/solve-scenario` 请求响应保持不变。
