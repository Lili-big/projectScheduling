# 根目录与生命周期契约

## 根目录允许项

- 七个生命周期阶段目录：`00-governance`～`06-delivery`。
- 发现入口：`.agents/`、`.specify/`。
- 本地数据：`.local-data/`。
- 根说明：`README.md`、`AGENTS.md`、`agent.md`。
- Git、环境、根构建工作区和平台明确要求的配置文件。
- 依赖目录和外部工具缓存仅可作为已忽略兼容项，必须出现在清理策略中。

## 根目录禁止项

- 新业务文档、脚本、JSON/Excel 输入、HTML/图片结果和运行日志。
- 新的通用 `docs`、`tools`、`outputs`、`output`、`logs` 所有权目录。
- 未登记原因的生成物、缓存、临时目录和项目业务 Skill。

## 阶段入口契约

每个阶段 README 必须包含：目的、进入条件、退出条件、权威资产、工作包索引、相邻阶段、禁止内容和维护触发条件。

## 工作包入口契约

每个工作包必须包含 `README.md` 和 `workpackage.json`。README 面向维护者解释运行和成果；JSON 面向 Agent 和治理检查。没有脚本的历史成果仍需工作包描述，并将状态标为 `orphaned` 或 `historical`。

## 迁移契约

物理移动前必须完成清单审批。任何目标冲突、哈希差异、跟踪状态差异或清单外变化都会停止对应批次；不得为完成批次而覆盖目标或删除未知文件。
