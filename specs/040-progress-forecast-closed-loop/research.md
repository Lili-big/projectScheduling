# 研究结论：进度锁定重排三步闭环

## 决策 1：三步状态采用派生状态，不单独持久化

- **决策**：步骤状态由活动计划、当前进度快照、最新预测、页面未保存修改和当前请求状态共同推导。
- **理由**：这些对象已经是业务事实源；额外保存步骤状态会在快照修订、计划切换或预测过期时产生不一致。
- **已评估的替代方案**：在存储中增加工作流步骤字段。该方案需要额外迁移和同步规则，且不能提供新的业务事实，因此拒绝。

## 决策 2：保存后不自动求解

- **决策**：有效快照保存成功后解锁并突出“锁定实绩并重排剩余计划”，由用户主动触发。
- **理由**：滚动预测包含 CP-SAT 求解，可能达到当前求解时限；自动触发会把一次保存变成不可预期的长操作，也不利于用户复核本次快照。
- **已评估的替代方案**：保存成功立即自动重排。交互更少，但失败边界模糊且增加不必要求解，拒绝。

## 决策 3：当前趋势保持现有资源和未来顺序

- **决策**：第二步继续使用 `as_is` 当前趋势，只锁定实绩并向后传播，不自由优化未开始任务顺序，也不增加资源。
- **理由**：第二步回答“照当前组织方式继续会怎样”；自由重排属于既有“关键任务优先”调整策略，混入当前趋势会掩盖真实风险。
- **已评估的替代方案**：第二步直接求最短工期。虽然可能给出更好日期，但会把优化方案误称为当前趋势，拒绝。

## 决策 4：节点必须在历史与未来合并计划上重新评估

- **决策**：先合并已完成任务实际日期和剩余任务预测日期，再评估项目完工和每个里程碑。
- **理由**：当前残余求解不包含已完成任务，只读取残余结果会让已完成节点或跨历史/未来范围节点出现“未评估”或日期错误。
- **已评估的替代方案**：继续直接使用残余求解的 `milestone_results`。无法覆盖历史任务，拒绝。

## 决策 5：结构化节点是新增兼容字段

- **决策**：在预测中新增 `critical_nodes` 和 `execution_summary`，保留现有 `risk_status`、`risk_evidence`、`metrics` 和 `milestone_results`。
- **理由**：现有泛化字典适合兼容摘要，但不能稳定承载日期来源、缓冲、状态、相关任务和证据，也难以做前端类型检查。
- **已评估的替代方案**：继续向 `risk_evidence` 填入更多任意键。实现快但契约不清、历史格式难测试，拒绝。

## 决策 6：关键节点主范围与预警阈值

- **决策**：主范围为项目完工节点和全部强制里程碑；其他里程碑作为次级结果。缓冲大于 3 天为预计按期，0–3 天为临近风险，负值为预计延期；无法获得日期时为无法判断。
- **理由**：与当前项目级 3 天缓冲口径一致，避免本期引入新的配置项；强制里程碑是需要行动的主要合同/强控节点。
- **已评估的替代方案**：新增每个里程碑独立阈值。产品灵活但会扩大里程碑配置和兼容范围，本期拒绝。

## 决策 7：错误提示在计划管控页面收敛

- **决策**：页面把网络不可达、业务校验、修订冲突和求解失败转换为带当前步骤语境的提示；不在本期全面重写全局请求客户端。
- **理由**：问题集中在计划管控闭环，局部收敛能降低对其他页面的回归风险。
- **已评估的替代方案**：全局改写所有 API 错误体系。范围过大且与本功能无直接关系，拒绝。

## 决策 8：兼容存储不升级 schema

- **决策**：新增预测字段使用默认空值，继续读取 `plan-control/v1`；只有新生成的预测包含完整节点结果。
- **理由**：旧预测仍可展示兼容摘要，活动输入变化后会按既有规则过期；无需重写用户历史文件。
- **已评估的替代方案**：升级 schema 并批量回填历史节点。回填缺少当时完整运行环境且可能改变历史结论，拒绝。

## 决策 9：暂停事实可保存，但缺少恢复日期不得确定性预测

- **决策**：暂停任务具备实际开始、暂停原因和人工剩余工期时允许保存；未填恢复日期则快照标记数据质量警告，滚动预测返回“无法判断”，不把暂停任务安排在状态日期立即复工。
- **理由**：进度快照应忠实保存现场未知事实；强制填写虚构恢复日期或静默立即复工都会扭曲预测。
- **已评估的替代方案**：阻断进度保存，或默认状态日期复工。前者丢失现场事实，后者产生虚假排程，均拒绝。

## 决策 10：项目完工目标使用活动计划基准完成日期

- **决策**：项目完工节点以当前活动计划快照的 `plan_finish_date` 为目标日期。
- **理由**：与现有完工偏差口径一致，并确保执行版本切换后使用对应版本目标。
- **已评估的替代方案**：使用状态日期加固定工期或预测日期反推目标。会改变已确认计划口径，拒绝。
