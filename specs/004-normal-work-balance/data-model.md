# 数据模型：普通工程差异化均衡目标

## 普通工程任务

**含义**：管控级别为普通，且不属于控制链前置影响范围的任务。

**关键属性**：

| 属性 | 含义 |
| --- | --- |
| 任务 ID | 用于关联排程、诊断和目标拆解 |
| 管控级别 | 必须为普通工程 |
| 控制链归属 | 不在控制链中才进入普通工程差异化处理 |
| 工期 | 用于统计工作量 |
| 计划开始/完成时间 | 用于计算统计桶分布 |
| 资源候选状态 | 决定进入资源连续施工目标还是未配置资源均衡目标 |

## 已配置受限资源普通工程

**含义**：普通工程任务存在至少一个启用的受限兼容资源候选。

**规则**：

- 不进入未配置资源普通工程均衡罚分。
- 继续参与资源空闲、资源路径连续性和同类资源工作量均衡。
- 结果解释应优先展示资源利用率、空闲、路径和同类资源工作量。

## 未配置受限资源普通工程

**含义**：普通工程任务没有启用的受限兼容资源候选，排程时按资源默认充足处理。

**规则**：

- 进入低优先级普通工程均衡目标。
- 不产生资源占用区间，不参与命名资源空闲和路径目标。
- 按周/月统计桶计算工作量集中风险。

## 普通工程均衡统计桶

**含义**：用于衡量未配置资源普通工程是否集中施工的时间段。

**字段**：

| 字段 | 含义 |
| --- | --- |
| 桶序号 | 从项目开始日期按周/月划分 |
| 开始偏移 | 该统计桶开始时间 |
| 结束偏移 | 该统计桶结束时间 |
| 实际工作量 | 桶内未配置资源普通工程的工期合计 |
| 理想工作量 | 可均衡任务总工期按桶数平均后的目标工作量 |
| 偏差 | 实际工作量与理想工作量的差异 |

## 未配置资源普通工程均衡罚分

**含义**：衡量未配置资源普通工程是否集中在少数时间桶。

**计算口径**：

```text
未配置资源普通工程均衡罚分 =
所有统计桶“实际工作量与理想工作量偏差”的合计
```

**输出口径**：

- `objective_breakdown` 中展示罚分、权重和目标贡献。
- `stats.normal_balance_metrics` 中展示参与任务数、已配置资源任务数、未配置资源任务数、桶分布和均衡评分。

## 兼容边界

- 旧 payload 中的 `normal_balance` 继续作为废弃输入忽略。
- 不新增前端可编辑目标项 ID。
- 如果前端不展示新字段，后端输出仍保持字典兼容。
