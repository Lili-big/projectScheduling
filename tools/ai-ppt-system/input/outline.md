# 基建智能计划管控中枢

## 基本信息

- PPT 主题：基建智能计划管控中枢
- 听众对象：客户项目管理层、计划工程师、施工技术人员
- 使用场景：客户整体产品方案沟通与试点共创
- 期望达成的目标：说明初始计划、动态管控和风险预警如何形成持续闭环
- 页数：14
- 风格要求：商务、克制、科技感，深蓝与工程橙搭配，适合客户现场投屏
- 输出格式要求：PPTX、HTML、PDF、PNG、Marp

## 内容大纲

1. 当前问题：计划编得出来；执行过程跟不下去；风险往往发现太晚。
2. 产品定位：从自动排程工具升级为智能计划决策中枢；统一数据与规则；连接计划与现场。
3. 完整闭环：初始计划编制；动态跟踪推演；风险处置与重新发布。
4. 初始计划：任务网络自动生成；双模式资源求解；经济平衡抢工三方案。
5. 动态管控：基准实际预测三态；偏差沿逻辑传播；调整方案对比。
6. 风险预警：六类进度风险；处置窗口与责任人；跟踪降级关闭。
7. 风险范围：节点与关键任务；资源与工效；逻辑工作面与数据。
8. 产品架构：项目数据与进度；三级规则与知识；排程预测风险引擎。
9. 能力边界：AI生成与解释；规则负责校验；CP-SAT验证可行。
10. Demo与蓝图：已验证计划与方案；下一步动态与预警；长期企业化协同。
11. 建设路线：初始计划试点；动态与风险闭环；企业化协同。
12. 试点场景：一座桥或一个工区；每周滚动更新；形成量化结论。

- 动态管控和风险预警明确标注为下一阶段产品方向。
