## 用户场景与测试

### 用户故事 1 - 按工点结构自动展示可能资源（优先级：P1）

计划工程师选择一个桥梁工点后，页面根据该工点当前启用的结构物、构件和采用工艺，自动列出可能需要配置的资源，不再把整个项目工艺目录中的资源机械展示给每个工点。

**优先级理由**：这是减少人工判断和避免错误配置的核心价值。

**独立测试**：准备包含不同结构与工艺的多个桥梁工点，逐个切换并核对自动资源行仅覆盖该工点结构实际可能使用的类型。

**验收场景**：

1. **假设**工点 A 有启用的桩基构件，且该桩基选用旋挖钻工艺，**当**用户进入 A 的资源配置，**则**默认资源中出现“旋挖钻机”，不同时展示回旋钻机、冲击钻机或人工挖孔班组。
2. **假设**工点 B 存在启用的现浇连续梁，**当**用户进入 B 的资源配置，**则**默认资源中出现“连续梁班组”，同一连续梁的多个施工任务不得形成重复资源行。
3. **假设**工点 C 没有连续梁，**当**用户进入 C 的资源配置，**则**不得仅因为项目工艺库存在连续梁工艺而展示“连续梁班组”。
4. **假设**工点包含承台、墩柱和盖梁，**当**页面派生默认资源，**则**分别展示对应资源；被禁用或不属于当前工点的结构构件不参与匹配。

---

### 用户故事 2 - 使用中文资源名称（优先级：P1）

计划工程师在默认资源列表、补充资源下拉框和已配置资源行中看到清晰的中文资源名称，不需要通过英文类型代码判断资源含义。

**优先级理由**：资源名称是高频业务信息，英文代码作为主名称会增加理解和误选成本。

**独立测试**：打开包含标准资源和自定义资源的工点，核对标准资源主名称均为中文，内部类型代码只作为辅助识别信息。

**验收场景**：

1. **假设**目录包含 `rotary_drill`、`cap_beam_team` 和 `cast_in_place_continuous_beam_team`，**当**页面展示资源，**则**主名称分别使用“旋挖钻机”“盖梁模板”和“连续梁班组”等中文业务名称。
2. **假设**资源已有非空中文配置名称，**当**页面展示该资源，**则**优先保留该中文名称，不被类型代码覆盖。
3. **假设**遇到没有正式中文名称的自定义资源类型，**当**页面展示，**则**使用中文未命名提示并保留类型代码辅助识别，不得只把英文代码作为主名称。

---

### 用户故事 3 - 自动匹配不等于自动投入（优先级：P2）

计划工程师可以看到系统建议的资源行，但只有在明确添加或编辑后才形成该工点的资源配置，系统不替用户决定实际投入数量。

**优先级理由**：结构物可以证明“可能需要”，不能证明现场已经投入多少资源。

**独立测试**：打开只有结构匹配、尚无资源配置的工点，验证建议行数量和上限均为 0、状态为未配置；保存前后不产生隐式资源记录。

**验收场景**：

1. **假设**工点结构匹配出旋挖钻机但尚未配置资源，**当**页面展示建议行，**则**当前投入为 0、可增上限为 0、状态为未配置，且不产生求解候选。
2. **假设**用户编辑建议行或点击添加，**当**保存配置，**则**只为当前工点创建一条对应资源类型的工点独享记录。
3. **假设**已配置资源后来不再被当前结构匹配，**当**用户重新进入页面，**则**该已配置记录仍可见并可人工移除，系统不得静默删除用户数据。

### 边界与异常场景

- 工点主数据或结构明细尚未加载成功时，不得用全项目工艺目录冒充匹配结果；页面应显示加载、失败或空态。
- 构件显式选择的工艺优先于同构件类型的默认工艺；未指定时才使用该构件类型的唯一默认工艺。
- 一个工点的多个构件或多个任务需要同一资源类型时，页面只显示一行。
- 同一桩基工点存在不同成桩方法时，应展示实际出现的各资源类型，每种类型一行。
- 工艺没有资源类型映射时不创建虚假资源；该工艺仍可按现有“默认充足”或其他既有规则处理。
- 页面自动匹配结果变化不得覆盖已保存的 `quantity`、`max_quantity`、启用状态、日历或成本属性。
- 完整资源目录仍允许补充当前结构未匹配的资源类型，但不得包含架桥机和梁场类型。
- 本功能不得创建或恢复 `PROJECT_SHARED` 资源池。

## 需求

### 功能需求

- **FR-001**：资源配置页面必须以中文业务名称作为资源项主名称，英文资源类型代码只能作为辅助识别信息。
- **FR-002**：系统必须为所有内置可配置资源类型提供稳定、非空且含中文字符的目录名称。
- **FR-003**：已配置资源池存在非空中文 `label` 时必须优先使用该名称；缺少正式中文名称的自定义类型必须显示中文未命名提示并保留类型代码。
- **FR-004**：系统必须按当前权威桥梁工点的启用结构、构件和采用工艺派生“可能使用的资源类型”。
- **FR-005**：桩基资源必须按构件实际选定的成桩方法匹配；未显式选择时使用适用的默认工艺，不得同时列出未采用的全部成桩设备。
- **FR-006**：现浇连续梁必须匹配连续梁班组；承台、墩柱、盖梁及其他具有资源映射的结构构件必须按其采用工艺匹配对应资源。
- **FR-007**：未启用、不属于当前工点或仅存在于全项目工艺库而当前工点没有对应结构的资源类型不得进入该工点自动匹配列表。
- **FR-008**：同一工点内相同资源类型必须去重为一条默认资源行，并保持确定性顺序。
- **FR-009**：自动匹配不得依赖已有资源池或已经成功求解；工点结构与工艺数据可用时，即使当前资源集合为空也必须得到匹配结果。
- **FR-010**：自动匹配结果必须是只读派生建议，初始 `quantity=0`、`max_quantity=0` 且未配置，不得自动持久化、自动启用或产生求解资源实例。
- **FR-011**：用户编辑或添加建议资源时，系统必须只创建或更新当前工点的 `WORKPOINT_EXCLUSIVE` 记录，同一工点同一类型保持唯一。
- **FR-012**：已配置但当前不再自动匹配的工点资源必须继续显示并保留原字段，直到用户明确移除。
- **FR-013**：用户必须能够从完整中文资源目录补充当前结构未匹配的资源；目录继续排除架桥机、梁场及其生产线。
- **FR-014**：工点或结构数据的加载、失败、空态和版本切换必须保持现有权威版本防旧响应覆盖规则，不得退化为展示全项目资源类型。
- **FR-015**：本功能不得新增或恢复共享资源数据，不得修改求解器对显式共享输入的兼容能力。
- **FR-016**：结构或工艺变化导致自动匹配集合变化时，当前资源页面必须使用新集合；已生成任务继续按现有场景指纹失效规则处理，历史结果和已保存资源记录不得被追溯改写。
- **FR-017**：系统必须为桩基方法、连续梁、普通下部结构、重复类型去重、空资源项目、自定义名称和版本切换提供可复现验证。

### 关键实体

- **中文资源目录项**：资源类型代码对应的中文业务名称、适用工艺和默认展示元数据；是只读投影，不代表实际投入。
- **工点结构资源需求**：由一个权威工点的启用结构构件及其选定或默认工艺派生的资源类型集合。
- **匹配资源建议行**：尚未持久化的页面行，表示当前工点可能需要该类型，初始数量和上限为 0。
- **工点独享资源记录**：用户确认后保存的实际配置，包含工点、类型、中文名称、数量、上限和状态。

## 派生与匹配规则

- **输入**：当前项目主数据版本、桥梁工点、启用结构与构件、构件 `method_id` 或等价工艺选择、工艺库资源类型映射、已有工点资源记录和只读资源目录。
- **输出**：当前工点去重、稳定排序的匹配资源类型集合，以及每个类型的中文目录名称；已有工点资源与匹配建议共同形成页面可见行。
- **优先级**：构件显式工艺及其资源映射 > 构件类型的默认工艺及其资源映射 > 无匹配；不得用任意非默认工艺或全项目目录填充。
- **硬规则**：匹配只判断“可能使用”，不改变资源数量、上限、状态和持久化；数量 0 仍表示没有实际资源；共享池数量保持 0。
- **去重规则**：以资源类型代码去重；多个结构、构件或工艺映射到同一类型时合并为一行，但不合并不同资源类型。
- **冲突处理**：同一构件存在多个显式有效工艺时保留其实际使用的各资源类型；工艺引用无效或没有资源映射时不猜测，并保留可诊断的缺失事实。
- **求解边界**：本功能不修改候选、互斥、容量或目标函数；只有用户保存且启用、数量大于 0 的工点资源才按现有规则进入计算。

## 成功标准

### 可衡量结果

- **SC-001**：标准资源目录及资源配置页内置资源主名称的中文覆盖率为 100%，仅以英文类型代码作为主名称的标准资源数量为 0。
- **SC-002**：固定多工点样例中，每个工点自动匹配资源与其启用结构及选定/默认工艺的期望集合完全一致，准确率和覆盖率均为 100%。
- **SC-003**：旋挖、回旋、冲击和人工挖孔四类桩基方法样例均只匹配实际采用的桩基资源，错误追加其他成桩资源次数为 0。
- **SC-004**：包含连续梁的工点匹配连续梁班组的覆盖率为 100%，不含连续梁的工点误显示连续梁班组次数为 0。
- **SC-005**：同工点重复结构映射同类型时资源行重复数为 0；匹配结果在等价输入下顺序变化次数为 0。
- **SC-006**：仅查看自动匹配建议并保存其他配置时，新增隐式资源记录数、自动启用数和自动投入数量均为 0。
- **SC-007**：结构匹配变化后，已有工点资源记录字段保真率为 100%，被系统静默删除的用户资源记录数为 0。
- **SC-008**：工点结构派生领域测试、页面运行时或等价可复现验证、类型检查、生产构建和文档验证完成，并记录任何非核心环境风险。

## 默认假设

- “默认资源”表示默认可见的待配置建议行，不表示系统已经投入或启用了该资源。
- 内置中文名称由统一只读资源目录维护；已配置的业务中文名称优先，类型代码继续保留用于接口、诊断和技术识别。
- 自动匹配以当前权威结构构件和实际采用工艺为准；没有显式工艺时复用现有默认工艺选择规则。
- 本期复用现有资源目录和结构/工艺模型，不新增可编辑目录主数据或新的持久化字段。
