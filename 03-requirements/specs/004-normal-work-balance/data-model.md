# 数据模型：普通工程差异化均衡诊断（历史目标口径修正）

> 当前实现校正（2026-07-08）：`normal_balance`、`unconfigured_normal_balance` 不再是当前目标函数项。本文件仅描述可保留的诊断数据结构，不能作为新增目标项、固定低优先级目标或 `weighted_objective` 贡献的依据。

## 普通工程任务

**含义**：管控级别为普通，且不属于控制链前置影响范围的任务。

**关键属性**：

| 属性 | 含义 |
| --- | --- |
| 任务 ID | 用于关联排程、诊断和目标拆解 |
| 管控级别 | 必须为普通工程 |
| 控制链归属 | 不在控制链中才进入普通工程差异化处理 |
| 工期 | 用于统计工作量 |
| 计划开始/完成时间 | 用于计算统计桶分布 |
| 资源候选状态 | 决定进入资源连续施工目标还是未配置资源均衡目标 |

## 已配置受限资源普通工程

**含义**：普通工程任务存在至少一个启用的受限兼容资源候选。

**规则**：

- 不产生未配置资源普通工程均衡的当前目标贡献。
- 继续参与资源空闲、资源路径连续性等当前资源目标。
- 结果解释应优先展示资源利用率、空闲和路径连续性。

## 未配置受限资源普通工程

**含义**：普通工程任务没有启用的受限兼容资源候选，排程时按资源默认充足处理。

**规则**：

- 可进入普通工程均衡诊断统计。
- 不产生资源占用区间，不参与命名资源空闲和路径目标。
- 可按周/月统计桶计算工作量集中风险，但不得进入当前目标函数。

## 普通工程均衡统计桶

**含义**：用于衡量未配置资源普通工程是否集中施工的时间段。

**字段**：

| 字段 | 含义 |
| --- | --- |
| 桶序号 | 从项目开始日期按周/月划分 |
| 开始偏移 | 该统计桶开始时间 |
| 结束偏移 | 该统计桶结束时间 |
| 实际工作量 | 桶内未配置资源普通工程的工期合计 |
| 理想工作量 | 可均衡任务总工期按桶数平均后的目标工作量 |
| 偏差 | 实际工作量与理想工作量的差异 |

## 未配置资源普通工程均衡诊断

**含义**：诊断未配置资源普通工程是否集中在少数时间桶。

**计算口径**：

```text
未配置资源普通工程均衡诊断值 =
所有统计桶“实际工作量与理想工作量偏差”的合计（仅诊断）
```

**输出口径**：

- 不在 `objective_breakdown` 中展示当前有效罚分、权重或目标贡献。
- 可在 `stats.normal_balance_metrics` 中展示参与任务数、已配置资源任务数、未配置资源任务数、桶分布和诊断评分。

## 兼容边界

- 旧 payload 中的 `normal_balance` 继续作为废弃输入忽略。
- 旧 payload 中的 `unconfigured_normal_balance` 继续作为废弃输入忽略。
- 不新增前端可编辑目标项 ID。
- 如果前端不展示新字段，后端输出仍保持字典兼容。
