# 机组双幅流转图界面契约

- 位置保留在071资源图之后的“机组施工顺序”，仅替换内部路线布局。
- 每次一机组，同工点/系列左右两幅固定共享递增里程域；中央两基线起日相同，左上/右下日期向外递增。显示“横向里程；向外日期推进；箭头为施工流转”。
- 工序真实作业时间片+施工段范围，起点/终点、访问编号和箭头可见。连线锚点仅为段中点示意，不代表段内真实运动。
- 默认全程线与当前前后突出，支持“仅看当前前后”、适应全程及时间放大；节点/边可点击或键盘选择，详情与前后导航配合，焦点可见。
- 稠密图允许普通标签省略名称，保留可读关键序号；选中目标必须完整可辨，放大或前后导航可访问所有到访，不能为避让修改数据位置。
- 跨幅连线端点按真实结束→开始，跨工点/系列使用可操作衔接说明，不跨越不可定位到访假连。转场未知明确标记，空档不冒充转场。
- 缺方案/缺分配空态，未知幅别/桩号/冲突单列原因，重叠/无效时间隐藏确定线并保留事实。新快照整图更新，历史不读取当前配置。
- 071资源图、任务横道、诊断和桥梁行为保持；不新增HTTP/持久字段或后台计算。
