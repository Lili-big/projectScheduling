# 验证指南：AI资源助手分步求解与独立推荐

## 前置条件

使用默认场景或导入可生成 A/B/C 三方案的项目数据；外部 LLM 可不配置，系统应使用本地回退。

## 验证步骤

1. 打开“AI资源助手”，点击“生成三方案”。
2. 点击“求解方案 A”，确认只有 A 进入求解中，完成后显示 A 的指标和计划。
3. 依次点击“求解方案 B”“求解方案 C”，确认每次仅更新对应方案，对比表逐步补全。
4. 在 B 或 C 未完成前，确认“生成 LLM 推荐”不可用并提示缺少方案。
5. 三方案完成后，点击“生成 LLM 推荐”，确认这时才发起解释请求并显示推荐或暂无推荐。
6. 修改方案 B 的一项资源数量，确认 B、完整对比与推荐失效，A/C 结果仍可见；重新求解 B 后再次生成推荐。

## 自动验证

```powershell
.\.venv\Scripts\python.exe -m pytest backend\tests\test_ai_resource_scheduling_assistant.py -q
npm.cmd run build
```

## 通过标准

- 单方案请求不调用 LLM 推荐解释。
- 对比刷新不运行 CP-SAT。
- 推荐在三方案完成后才可触发，LLM 失败仍返回本地解释。
