## 3. 页面验收矩阵

以系统当前日期 2026-07-14、状态日期 2026-07-13 为例，日期上限为 2026-07-13。

| 计划日期 | 操作 | 期望 |
|---|---|---|
| 07-10 至 07-20 | 切换进行中 | 实际开始 07-10，实际完成空，开始标“系统建议” |
| 07-15 至 07-20 | 切换进行中 | 实际开始 07-13，表达提前开工 |

| 已有实际开始 | 切换取消 | 已有开始保留，不新增完成日期 |

## 4. 人工事实保护

1. 将任务切换为进行中，确认实际开始出现“系统建议”。
2. 手工改为另一个合法日期，确认建议标记消失。
3. 修改状态日期，确认人工日期不变。
4. 选择另一个仍保持系统建议的任务，修改状态日期，确认建议按新上限重算。
5. 保存成功后再次修改状态日期，确认服务端回显日期不再被自动重算。

## 5. 历史与失败场景

- 刷新或重新加载当前快照：已有日期不显示“系统建议”，空日期不被补齐。
- 人工填入晚于状态日期的实际日期并保存：后端拒绝，页面保留草稿并显示可定位错误。
- 人工填入早于实际开始的完成日期并保存：后端拒绝日期顺序错误。
- 计划日期缺失或倒置：任务行显示计划日期不可用，不生成建议，仍可人工输入。
- 保存接口失败：建议仍是未保存草稿，不显示保存成功消息。
- 切换项目、筛选、分页：项目切换清空旧草稿；筛选和分页不改变当前项目草稿。

## 6. 非回归核对

- 总工程量、实际完成比例、已完工程量和剩余工程量联动保持不变。
- 保存后滚动预测、风险分析和调整方案入口保持不变。
- 不产生新的 API 字段、JSON 存储字段或历史迁移文件。
- 任务排程、资源配置、里程碑和 CP-SAT 求解结果不变。
