# 需求发现：根目录生命周期工作区治理

## 已确认目标

用户确认本项目应从根目录层面按产品生命周期组织，而不是只在 `docs/` 内建立文档导航。目标覆盖前期需求调研、过程方案分析、需求文档设计、Demo 实现、客户验证和正式交付，并使每个阶段的材料、脚本、输入和成果可以在同一阶段下理解和维护。

同时确认以下补充目标：

- 独立 JSON 展示工具及其输入、脚本、HTML/JSON 成果应形成独立工作包。
- AI 案例总结、申报材料及其生成脚本应形成独立工作包。
- 客户验证总结、分析脚本、数据和成果应形成独立工作包。
- 日志、缓存、临时文件、本地状态、用户输入和正式交付物必须分级，避免误删。
- 本次变更不是一次性整理；后续 Agent 和维护者必须根据任务归属自动选择阶段、工作包和保留策略。

## 已确认组织模型

采用三层模型：

```text
生命周期阶段
  -> 独立工作包
    -> 输入 / 脚本 / 成果 / 本地产物
```

根目录目标阶段为：

1. `00-governance`：项目治理、架构、仓库工具和 Skill 目录。
2. `01-discovery`：客户资料、访谈、原始证据和调研分析。
3. `02-solution-analysis`：产品方向、方案比较、决策和概念验证。
4. `03-requirements`：产品需求、算法规则、规格、模板和需求工具。
5. `04-demo`：后端、前端、部署、样例、Demo Skill 和独立展示工具。
6. `05-validation`：验证计划、客户/工程验证工作包、数据、脚本和结果。
7. `06-delivery`：正式交付物、案例总结、申报材料、演示材料和构建器。

`.agents/` 与 `.specify/` 作为工具发现入口保留在根目录；根入口文档、构建清单和平台要求的配置文件也允许保留。其他业务资产不得继续使用含义模糊的根 `docs/`、`tools/`、`outputs/` 作为长期所有权目录。

## 当前项目事实

- 当前主要受跟踪资产分散在 `backend/`、`frontend/`、`docs/`、`tools/`、`examples/`、`deliverables/`、`specs/`。
- `local-json-task-review/` 同时包含 JSON 输入、生成脚本、HTML/JSON 结果和截图，但整体被忽略，缺少可复用脚本与本地案例的分层。
- `examples/result-viewer/` 保存可分发 JSON/HTML 查看器，与本地 JSON 工作区职责重叠。
- `outputs/lugu-report-*`、`outputs/lugu-validation-*` 同时包含分析脚本和成果，缺少稳定归属。
- `docs/archive/application-case/` 和 `deliverables/awards/` 可定位 AI 案例成果，但当前可见生成脚本与成果之间没有稳定、可机器检查的绑定。
- 根 `logs/`、`.local-data/logs/`、多种缓存和构建目录并存；`.local-data` 中同时存在不能清理的业务状态和可以清理的日志/临时文件。
- 当前 Constitution、`AGENTS.md` 和 Spec Kit 脚本仍规定 `docs/`、根 `specs/` 为固定位置，实施新结构前必须显式升级治理契约和工具路径。

## 默认决策

- 每个资产只有一个主要阶段和一个主要工作包；跨阶段只链接，不复制。
- `backend/`、`frontend/` 实体迁入 `04-demo/`；现有启动、构建、测试和部署入口同步调整。
- 规格实体迁入 `03-requirements/specs/`；`.specify/` 保留为根工具入口并更新定位逻辑。
- 通用 Spec Kit Skill 保留在 `.agents/skills/`；业务 Skill 的内容按阶段维护，发现入口保留兼容层。
- 独立工作包必须提供人类可读说明和机器可读描述，记录输入、脚本、成果、跟踪策略和清理等级。
- 清理工具默认只预览；用户输入、正式交付物和持久化状态永不作为缓存自动删除。
- 当前工作树中的既有修改、未跟踪业务资产和 042/043 产物均视为清单外保护对象，未经逐项确认不得移动或删除。

## 建议进入 Spec Kit 的输入摘要

重构仓库根目录，使生命周期阶段成为第一层业务所有权，工作包成为脚本和成果的最小维护单元，并通过 Agent 规则、机器描述、根目录白名单、引用校验和安全清理策略保证后续任务持续按归属落盘。变更必须保持 Demo 行为、公开接口、历史内容、正式交付物和用户本地数据不丢失，并对所有物理迁移提供逐项清单、哈希、跟踪策略和回退动作。
