# 仓库结构与资产治理契约

## 1. 根目录白名单原则

根目录仅保留以下类别：

- 项目入口与治理：`README.md`、`AGENTS.md`、`agent.md`。
- 构建与部署配置：`package.json`、锁文件、`requirements.txt`、`Dockerfile`、`netlify.toml`、环境变量示例和 ignore 文件。
- 一级主目录：`backend/`、`frontend/`、`docs/`、`specs/`、`examples/`、`tools/`、`deliverables/`、`artifacts/`。
- 经代码和部署验证必须暂留根目录的兼容样例数据；迁移完成后移出白名单。

新增根目录业务文档、临时脚本、预览文件、日志或生成结果均视为治理失败。

## 2. 文档职责

| 文档 | 唯一主要职责 | 不应承载 |
| --- | --- | --- |
| `README.md` | 项目定位、当前能力、快速启动、验证、部署、最短目录地图 | 详细模块百科、历史 PRD 全文、未实现目标 |
| `AGENTS.md` | 工作流分流和实施门禁 | 代码目录百科、运行命令大全 |
| `agent.md` | 当前事实、模块所有权、调用链、兼容边界、修改与验证矩阵 | 重复 README 教程、把规格目标写成现状 |
| `docs/README.md` | 文档分类、状态、权威范围、替代关系、维护触发条件 | 业务规则正文 |
| `docs/architecture/*` | 系统上下文、模块边界、依赖方向、运行部署和 ADR | 首次启动教程 |
| `specs/README.md` | 规格索引、状态和历史说明 | 改写历史 spec 内容 |

## 3. 资产分类与版本控制

| 类型 | 目标位置 | 默认跟踪 |
| --- | --- | --- |
| 主应用源码/配置 | `backend/`、`frontend/`、根配置 | 是 |
| 产品/工程文档 | `docs/` 对应分类 | 是 |
| Spec Kit 产物 | `specs/` 原目录 | 是 |
| 可复现样例 | `examples/` | 是 |
| 可复用辅助工具 | `tools/` | 源码、模板、必要资产跟踪 |
| 正式最终交付件 | `deliverables/` | 经清单确认后跟踪 |
| 预览、检查、构建中间件 | `artifacts/` | 否，除非显式 allowlist |
| 日志、缓存、密钥、依赖、临时锁文件 | 本地工作目录/忽略目录 | 否 |

## 4. 迁移规则

- 执行任何 `git mv`、取消跟踪或正式交付物分区前，必须先提交逐文件资产清单并取得用户二次明确确认；未确认项保持原路径和跟踪状态。
- 所有跟踪文件迁移使用 `git mv` 语义并更新当前引用。
- 二进制正式资产迁移前后必须记录并核对哈希。
- 历史 specs 不移动、不重编号；重复编号作为历史事实保留。
- `~$*`、已忽略仍跟踪的本地配置、可再生成预览和检查中间件，先确认无正式交付价值，再仅取消版本跟踪；不得批量删除用户本地文件。
- 样例 Excel 在兼容搜索、Docker、文档和测试就绪前暂留根目录。
- 旧路径无法保留文件级 façade 时，必须在 `docs/archive/path-migration.md` 记录旧路径、新路径、迁移日期和替代文档。

## 5. 文档状态

文档条目必须使用以下状态之一：

- `current`：描述当前实现并作为权威入口。
- `draft`：正在确认，不能作为当前实现依据。
- `superseded`：已被替代，必须指向新文档。
- `historical`：保留审计，不再指导当前实现。
- `missing_source`：历史引用的目标已缺失，必须记录但不能伪造。

## 6. 自动检查最低范围

- 根目录白名单。
- 无跟踪的 `~$*`、`.local.env`、日志、缓存、依赖和构建目录。
- 生成物仅在显式 allowlist 中跟踪。
- `README.md`、`agent.md`、`docs/README.md`、`docs/architecture/` 内部链接 100% 有效。
- 入口文档的脚本、API、环境变量和部署路径可从代码/配置事实验证。
- `specs/README.md` 中每个规格目录存在且状态可解释。
- 正式交付物清单包含来源、用途、日期、哈希和是否可再生成。
- Python/npm 运行时依赖与 Batch 0 基线一致；新增包、升级或锁文件依赖树变化必须有独立确认记录。
- 迁移后的辅助工具、参考 API 和交付物构建器均有可运行验证证据，不能只验证路径存在。
