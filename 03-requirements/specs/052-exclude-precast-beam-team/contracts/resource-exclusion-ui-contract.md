# 预制梁班组资源排除 UI 契约

## 输入

- 当前工艺库中可能存在 `precast_beam → precast_beam_team` 映射。
- 当前工点详情中可能存在启用的 `precast_beam` 构件。
- 当前资源目录统一排除集合包含 `precast_beam_team`。

## 输出

- 工点自动建议中 `precast_beam_team` 数量为 0。
- “从资源目录补充”选项中 `precast_beam_team` 数量为 0。
- 桩基、承台、墩柱、盖梁、连续梁和 `beam_erection_team` 等未排除类型继续按 050 规则输出。

## 兼容边界

- 不新增或调用梁场配置接口。
- 不改变预制梁工艺任务、工期或求解器。
- 不自动删除历史显式资源数据；本契约只定义当前工点资源目录的可见与可选范围。
- 梁场专项缺失时也不得恢复该类型作为兜底。
