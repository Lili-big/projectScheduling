# UI 行为契约：AI 快速配置工装

## 入口

- 入口位于现有“工点资源配置”标题操作区，按钮文案为“AI快速配置工装”。
- 不新增导航、页面、弹窗式全量预览或第二个保存按钮。
- 当前项目主数据工点未就绪、正在调用 AI 或正在保存资源时，按钮禁用。

## 调用前

- 请求使用当前页面的完整场景状态，包括尚未保存的人工资源修改。
- 用户已有的本地资源、共享池及任何其他资源记录都属于冻结输入。
- 项目无确认版本、无桥梁工点、结构资料不完整时显示对应提示，不发送模型请求。

## 调用中

- 按钮显示加载状态并禁止重复点击。
- 用户仍可看到当前工点页面，但不得在同一批次进行第二次 AI 调用。
- 调用令牌绑定 `project_data_version_id + resource semantic fingerprint`。

## 成功

- 响应仍对应当前调用令牌时，通过一次 Workspace 状态更新追加 `resource_pools_to_add`。
- 合并前再次按池 ID 和 `工点 ID + 资源类型` 去重；碰到冲突则整批不应用并要求重新生成。
- 成功通知只展示新增资源数、涉及工点数、无需补充工点数和模型名称，不创建集中编辑列表。
- 用户通过现有工点标签逐个查看；新增行沿用当前投入、可增上限、状态和操作控件。
- 页面进入“资源配置未保存”状态；只有点击现有“保存”才持久化。

## 失败或过期

- 真实模型未配置：提示用户在 `.local.env` 配置 `AI_RESOURCE_ASSISTANT_*` 并重启后端。
- 鉴权、网络、超时或模型服务失败：显示可行动错误，资源状态不变。
- 模型输出非法：显示后端校验摘要，不展示或应用有效子集。
- 项目版本或资源状态已变化：丢弃迟到响应，提示重新点击；不得覆盖用户的新修改。
- 错误文案不得包含 endpoint 完整查询参数、API Key、Authorization 或原始认证响应。

## 保存

- 继续调用现有“保存”操作，提交当前完整 `resource_pools`。
- 保存成功后沿用现有资源输入变化失效行为。
- 保存失败时 AI 新增和用户修改仍保留在页面临时状态，可修复后重试保存。
