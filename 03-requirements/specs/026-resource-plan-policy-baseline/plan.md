# 实施计划：三方案资源策略基线与 LLM 校验

**目录**：`026-resource-plan-policy-baseline` | **日期**：2026-07-12 | **规格**：[spec.md](./spec.md)

## 概要

在现有 AI 资源助手中新增项目化的确定性三方案基线与严格校验。后端先从当前生成任务计算资源实际工作量状态，再生成经济、平衡、抢工基线；LLM 在该边界内补充方案策略并允许有限数量调整。输出不合法时携带校验错误重试一次，仍失败则返回本次基线。零工作量和禁用资源在三版中强制为 0，原始 `max_quantity` 不得被放宽，求解前不产生最终推荐。

## 处理流程

1. 使用现有任务生成链路构造项目画像与任务需求。
2. 按资源类型汇总匹配任务数、累计需求工期、启用状态和原始上限，生成资源工作量状态。
3. 从状态、控制墩、连续梁主墩关系和当前资源池生成三版确定性基线。
4. 将基线和硬规则加入现有 LLM 项目上下文，保持当前方案输出字段不变。
5. 对 LLM 三版草案执行全量校验；非法时传回结构化错误并重试一次。
6. 合法则采用草案；重试失败、未配置或调用失败则采用本次确定性基线。
7. 继续复用现有方案卡、求解和求解后推荐流程。

## 基线规则

- 零工作量、未映射、禁用、数据异常资源：`0 / 0 / 0`。
- 桩基类：按实际工艺独立计算；不使用的工艺不得继承固定样例数量。
- 墩柱类：经济 `max(控制墩数, ceil(当前数量×0.75))`；平衡 `max(经济, 当前数量)`；抢工 `max(平衡, 当前数量 + ceil(控制墩数×0.5))`。
- 承台、盖梁：基于匹配工作量和墩柱投入，控制系数分别为经济 `0.5`、平衡 `0.5`、抢工 `0.75`，至少满足有效工作量的最小投入。
- 连续梁班组：设真实连续梁组数为 `T`，经济 `ceil(T×0.5)`，平衡 `T`，抢工 `T`，并受实际可施工组数约束。
- 其他有效资源：以当前数量为中心使用约 `0.75 / 1.0 / 1.25` 三档，再执行非负整数、单调性和原始上限裁剪。
- 若专项公式与通用规则冲突，专项规则优先；所有结果最终经过统一校验。
