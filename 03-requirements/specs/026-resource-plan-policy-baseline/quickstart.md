# 快速验证：三方案资源策略基线与 LLM 校验

## 前置条件

- 使用仓库现有 Python 测试环境和前端依赖。
- 不需要配置真实外部 LLM；测试通过替身覆盖各 Provider 路径。

## 场景 1：零工作量工艺归零

1. 构造只有旋挖钻任务的场景，资源池同时包含人工挖孔、冲击钻、回旋钻和旋挖钻。
2. 生成三版方案。
3. 期望：前三类资源均为 `[0, 0, 0]`；旋挖钻为非零且满足经济不高于平衡、平衡不高于抢工。

## 场景 2：项目化基线

1. 使用当前默认项目构建三方案基线。
2. 核对控制墩数量、连续梁组与主墩字段、任务需求工期和原始资源上限。
3. 期望：墩柱、承台、盖梁、连续梁班组按专项规则计算；其他有效资源按通用三档策略计算。

## 场景 3：非法输出纠错与回退

1. 首次 LLM 输出令零工作量资源为正数，第二次返回合法结果。
2. 期望：调用两次，第二次输入包含结构化错误，最终采用合法结果。
3. 再模拟两次均非法。
4. 期望：最终采用确定性基线，未扩大任何 `max_quantity`。

## 场景 4：兼容路径

分别验证外部 LLM 合法、本地 Provider、未配置和外部调用失败；均应返回恰好三版合法方案，并保持现有 `llm_generation_context` 与页面契约。
