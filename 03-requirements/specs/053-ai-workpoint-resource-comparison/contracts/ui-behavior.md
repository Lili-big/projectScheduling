# UI 行为契约：AI 多方案按工点推进资源

## 比选态布局

1. AI 多方案标题区下方、基准确认区之前提供“资源推进工点”单选下拉框。
2. 下拉数据来自当前场景桥梁工点；初始占位为“请选择工点”。
3. 同名工点使用名称加稳定短 ID 或既有可区分结构信息展示。
4. 页面持续显示“AI 仅调整所选工点本地资源；求解和指标仍为全项目口径”。

## 操作门禁

| 状态 | 生成三方案 | 求解/推荐/确认基准 |
|---|---|---|
| 无项目场景 | 禁用 | 禁用 |
| 无桥梁工点 | 禁用，显示空态 | 禁用 |
| 未选择工点 | 禁用，提示先选择 | 禁用 |
| 已选择但无合法可调本地资源 | 禁用或请求返回错误后保持禁用，提供资源配置指引 | 禁用 |
| 已选择且可调 | 启用 | 生成方案后按现有状态启用 |

## 方案卡

- 卡片只展示目标工点的可调本地资源行。
- 不显示共享池或其他工点的数量输入框。
- 卡片标题或说明展示目标工点名称。
- 求解结果、指标、详情和推荐区域标明“全项目排程结果”。

## 切换和失效

- 用户改选工点后立即退出详情态，并清空方案、结果、比较、推荐、下载上下文、选中项和本轮基准确认状态。
- 不弹出二次确认，不删除已持久化历史。
- 旧工点的生成、更新、求解、比较或推荐响应晚到时静默丢弃，不显示为当前工点错误或结果。
- 项目版本变化时连同工点选择一起清空，不按同名自动恢复。

## 错误与空态

- 无工点：`当前项目没有可参与 AI 资源推进的桥梁工点。`
- 未选择：`请先选择资源推进工点。`
- 无可调资源：`所选工点没有可由 AI 调整的本地资源，请先到资源配置维护。`
- 身份失效：`所选工点已不属于当前项目版本，请重新选择。`
- 越权资源响应：显示后端错误并保留当前工点选择，不接纳部分方案。
