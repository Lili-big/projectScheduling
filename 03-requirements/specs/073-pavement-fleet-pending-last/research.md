# 研究与决策

2026-09-28；业务口径无待澄清项，无新增依赖研究。

- 现有机组路径禁止从待移交任务返回正常任务，且资源选择是真实分配变量。去掉全局正常完工门槛即可将 CP-SAT 后置范围收敛到单套实例，不必新增两两约束。
- 初解和独立数值校验目前都有全局门槛，必须一并调整，否则合法的跨机组交错可能被过滤或报告不一致。
- 规则取实际分配，不按资源类型/资源池/可选资源集合。未被分配正常任务的机组不需等待其他实例。
- 采用 `per_fleet_last` 与历史 `strict_last` 区分。拒绝直接改写 strict_last 含义，因为已有结果与输入会失去可追溯性；拒绝新增用户可选策略开关，因为用户已明确替换旧规则。
- 初解顺序是启发式构造，绝非新的硬规则；对受阻构造保留 CP-SAT 兜底。数值校验与求解模型按同一实际路线不变量判定。
- API 演示镜像对路面明确返回 422，维持此能力边界。无需新增镜像排程实现。
- 当前客户 272 天是未证明最优的可行方案；本变更只消除无关跨机组等待门槛，不承诺缩短固定天数。

证据：`pavement.py::_build_model`、`constraints/pavement.py::forbidden_fleet_edges/add_pavement_fleet_paths`、`pavement_heuristic.py::construct_candidate/validate_candidate`、`api.mts` 路面拒绝分支。路径归属见 [plan.md](./plan.md)。
