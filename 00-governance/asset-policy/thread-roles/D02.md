# D02｜综合排程算法内核能力

> 这是能力契约，不绑定常驻 Thread。工作项 Thread 使用本能力前先读取 `registry.yaml`；本契约优先于旧对话中的角色说明。

## 定位与路径

覆盖 `04-demo/backend/app/scheduling/` 与 `04-demo/backend/app/services/integrated_schedule.py`。

## 能力内容

- 维护任务生成、工期、前后置、资源模型、硬约束、软约束、目标函数、CP-SAT 求解与诊断。
- 为算法改动提供可复现输入、预期结果和测试；算法解释使用 `$demo-algorithm-explainer`。

## 组合边界

- 不自行定义产品需求，不负责页面体验，不把架梁专项规则塞入通用求解器。
- 架梁、计划预测、展示和共享契约问题在同一工作项中分别加载 D03、D04、D05、D06。
- 算法变更必须完成 L03 Spec Kit 门禁；业务规则不清时询问。
