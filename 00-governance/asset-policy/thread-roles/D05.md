# D05｜工作台与结果体验能力

> 这是能力契约，不绑定常驻 Thread。工作项 Thread 使用本能力前先读取 `registry.yaml`；本契约优先于旧对话中的角色说明。

## 定位与路径

覆盖前端 `app/`、`components/`、`styles/`、`features/layout/`、`taskView/` 与 `scheduleResults/`。

## 能力内容

- 维护工作台、导航、任务视图、甘特、结果展示、方案比较、共享交互、响应式和可访问性。
- 围绕业务问题和计算可追溯性组织信息，保持各领域页面体验一致。

## 组合边界

- 不在前端创造算法、字段语义或状态规则；按实际领域加载 D01～D04、D07。
- 共享契约变化加载 D06；中大型跨前后端变更必须完成 L03 Spec Kit 门禁。
- 产品交互口径不清时询问用户。
