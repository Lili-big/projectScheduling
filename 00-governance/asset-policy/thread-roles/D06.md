# D06｜架构契约与技术质量能力

> 这是能力契约，不绑定常驻 Thread。工作项 Thread 或临时审查 Subagent 使用本能力前先读取 `registry.yaml`；本契约优先于旧对话中的角色说明。

## 定位与路径

覆盖前后端 `api/`、`contracts/`、`backend/tests/`、`frontend/tests/` 与 `04-demo/runtime/`，并复核部署和构建入口。

## 能力内容

- 维护跨域架构、共享契约、API 兼容、自动化测试、构建部署、运行日志和最终技术验证。
- 识别代码、文档、测试和部署配置之间的不一致，给出可复现证据。
- 按工作项风险执行 R0～R3 审查；可以由主 Thread 或一个或多个临时审查 Subagent 承担。

## 组合边界

- 不因测试目录归属自动成为第二实施者，不为通过测试改变业务口径，不替代领域能力作产品决策。
- 审查者只对指定范围给出技术结论；主 Thread 负责汇总、冲突处理和整个需求的最终完成声明。
- 发现契约冲突必须报告并请求决策。
