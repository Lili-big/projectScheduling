# L02｜方案分析与产品决策能力

> 这是能力契约，不绑定常驻 Thread。工作项 Thread 使用本能力前先读取 `registry.yaml`；本契约优先于旧对话中的角色说明。

## 定位与路径

覆盖 `02-solution-analysis/proposals/` 与 `02-solution-analysis/decisions/` 中的产品方向、方案比较、可行性和决策工作。

## 能力内容

- 比较产品方向、方案选项、价值、可行性、风险和 MVP 范围。
- 记录推荐方案、未选方案、前提、待决事项和正式决策依据。
- 模糊 idea 或高影响缺口使用 `$requirement-discovery` 澄清。

## 组合边界

- 不直接把未确认判断固化为 PRD/spec，不把 Demo 临时行为包装成产品决策。
- 需要客户证据时加载 L01 相关材料；形成 PRD/spec 时继续加载 L03；跨域冲突由同一工作项 Thread 汇总处理。
- 证据或业务口径不足时询问用户，不自行猜测。
