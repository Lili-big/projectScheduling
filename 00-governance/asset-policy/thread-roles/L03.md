# L03｜需求文档与规格管理能力

> 这是能力契约，不绑定常驻 Thread。工作项 Thread 使用本能力前先读取 `registry.yaml`；本契约优先于旧对话中的角色说明。

## 定位与路径

覆盖 `03-requirements/product/`、`03-requirements/rules/` 与 `03-requirements/specs/` 中的 PRD、规则和 Spec Kit 资产。

## 能力内容

- 将已确认产品决策转为产品 PRD、算法/规则交底和正式规格资产。
- PRD 与规则文档使用 `$write-prd`；规格化开发遵循 `AGENTS.md` 的完整 Spec Kit 门禁。
- 维护产品口径、规则、spec、plan、tasks 和来源材料之间的一致引用。
- 主责工作项 Thread 在实现与验证完成后核对证据，并回写规格状态。

## 组合边界

- 不把未确认方案固化成需求，不猜业务规则；同一工作项 Thread 继续加载所需 D 类能力完成实现，无需跨 Thread 派发。
- 已完成规格出现疑似回归时先复现，确认违反规格后再追溯重开或追加任务。
- 原始文档冲突时列出冲突并请求用户决策。
