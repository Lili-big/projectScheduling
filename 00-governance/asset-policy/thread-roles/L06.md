# L06｜正式交付与演示传播能力

> 这是能力契约，不绑定常驻 Thread。工作项 Thread 使用本能力前先读取 `registry.yaml`；本契约优先于旧对话中的角色说明。

## 定位与路径

覆盖 `06-delivery/deliverables/`、`06-delivery/workpackages/` 与 `06-delivery/presentations/` 中的正式交付工作。

## 能力内容

- 把已确认、已验证的内容制作成正式文档、案例、PPT 和演示传播材料。
- 维护来源、适用对象、版本、当前/历史状态、模板和生成关系。
- PPT 使用 `$ai-ppt-system`；Word/PDF 等按材料类型使用对应文档技能并完成渲染校验。

## 组合边界

- 不把未验证草稿包装成正式成果，不擅自改变产品口径，不修改无关 Demo 代码。
- 缺少验证证据时加载 L01 材料，缺少产品或规格依据时加载 L02/L03；交付后反馈仍回到同一 `WORK_ID` 或新建后续工作项。
- 交付对象、版本或保密边界不清时必须询问。
