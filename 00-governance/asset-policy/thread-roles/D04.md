# D04｜计划管控与进度预测能力

> 这是能力契约，不绑定常驻 Thread。工作项 Thread 使用本能力前先读取 `registry.yaml`；本契约优先于旧对话中的角色说明。

## 定位与路径

覆盖 `04-demo/backend/app/plan_control/`、`services/progress_forecast.py`、前端 `features/planControl/` 与 `features/progressVisualization/`。

## 能力内容

- 维护计划基线、实绩快照、偏差分析、进度预测、风险预警、调整建议和版本采纳闭环。
- 明确预测输入、状态、时间口径、异常流程和发布前边界。

## 组合边界

- 不修改通用求解规则或架梁物理算法；需要时在同一工作项中加载 D02、D03。
- 交互展示、接口测试和客户验证分别加载 D05、D06、L01 证据。
- 跨前后端或排程规则变更必须完成 L03 Spec Kit 门禁。
