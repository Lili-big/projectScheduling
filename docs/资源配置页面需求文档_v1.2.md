# 资源配置页面需求文档

版本：v1.2

日期：2026-07-09

适用范围：桥梁自动排程系统工程化版本资源配置页面

面向对象：产品、前端研发、后端研发、测试

## 1. 功能模块核心定位

### 1.1 模块定位

资源配置页面是排程系统的项目级资源约束配置模块，用于维护当前项目或当前排程方案中的受限资源池。系统根据资源池配置生成任务候选资源、展开命名资源，并在求解阶段约束同一资源同一时间只能执行一个任务，同时按资源池规则处理同结构同工艺任务的并行施工边界。

本期资源配置页面聚焦资源容量约束。页面需要让计划工程师或技术负责人明确当前方案中各类关键资源的默认投入数量、可增配上限和启用状态，从而支撑“固定资源求最短工期”和“固定工期求最少资源”两类排程测算。

### 1.2 当前页面效果和业务场景

用户进入资源配置页面后，页面展示当前方案下的资源池卡片列表。每张卡片展示资源名称、资源类型编码、默认投入数量、可增配上限数量、启用开关和并行施工说明。

典型业务场景包括：

- 计划工程师根据现场已有设备和班组，录入各类关键资源的默认投入数量。
- 技术负责人根据可协调资源上限，录入固定工期测算时允许系统推荐的可增配上限数量。
- 当当前默认资源可排程但未满足硬里程碑或固定工期目标时，系统只能在默认投入数量到可增配上限数量之间搜索候选资源。
- 用户临时关闭某类资源，查看当前方案在该类资源按默认充足处理时的任务图诊断和求解结果。
- 用户修改资源配置后重新生成任务图或重新求解，查看资源投入对工期、资源分配和里程碑达成情况的影响。

### 1.3 模块边界

本期覆盖：

- 查看资源池名称、资源类型编码、默认投入数量、可增配上限数量和启用状态。
- 查看资源池并行施工说明。
- 编辑资源池默认投入数量、可增配上限数量和启用状态。
- 资源池数量合法性校验。
- 默认连续自然日资源日历只读使用。
- 资源配置变更后使已有任务图、求解结果和方案对比结果失效。
- 资源配置参与任务候选资源、命名资源展开和求解器资源约束。

## 2. 数据定义

### 2.1 主数据对象

资源配置页面以项目或排程方案级 `ScenarioInput` 中的 `resource_pools` 和 `resource_calendars` 为数据来源。实际工程版本中，系统应支持从系统资源模板初始化到项目级配置，用户后续修改作用于当前项目或当前方案。

| 数据对象 | 说明 | 页面用途 |
| --- | --- | --- |
| `ResourcePool` | 资源池配置，描述某类受限资源的名称、类型、数量、日历和启用状态 | 页面主要编辑对象 |
| `ResourceCalendar` | 资源日历，描述资源工作日和停工日期 | 本期只读使用默认连续自然日 |
| `ProcessTemplate` | 工艺模板，包含默认资源类型 | 用于任务生成时匹配资源池 |
| `GeneratedScheduleInput` | 已生成的求解前任务图 | 用于验证资源候选和命名资源展开结果 |

### 2.2 资源池字段

资源池对应后端和前端的 `ResourcePool`。本期页面只编辑容量约束相关字段，并只读展示资源并行施工规则字段。

| 字段 | 类型 | 必填 | 页面状态 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | string | 是 | 只读 / 内部使用 | 资源池稳定 ID，用于保存、诊断和结果回溯 |
| `type` | string | 是 | 只读展示 | 资源类型编码，用于任务候选资源匹配和命名资源展开 |
| `label` | string | 是 | 只读展示 | 页面展示名称，如旋挖钻、承台模板 |
| `resource_mode` | enum | 是 | 只读 | 本期固定为受限资源模式 |
| `quantity` | number | 是 | 可编辑 | 默认投入数量，用于固定资源求工期，也是新增资源分支和固定工期求资源的搜索下界 |
| `max_quantity` | number | 是 | 可编辑 | 可增配上限数量，用于固定工期求资源和新增资源分支的搜索上界 |
| `calendar_id` | string | 是 | 只读 / 内部使用 | 本期默认引用连续自然日日历 |
| `enabled` | boolean | 是 | 可编辑 | 是否启用该资源池参与受限资源约束 |
| `compatible_process_ids` | string[] | 否 | 内部使用 | 可兼容工艺扩展字段，本期由后端维护 |
| `same_structure_resource_binding` | boolean | 否 | 只读 / 内部使用 | 同一结构物、同一构件类型、同一工艺的任务是否必须绑定到同一命名资源 |
| `parallel_rule_description` | string | 否 | 只读展示 | 面向用户解释该资源池并行施工规则 |

成本相关字段列入后续能力范围；本期页面隐藏这些字段，保存校验和验收均围绕资源容量字段展开。

### 2.2.1 资源搜索范围和最大资源提示

固定资源求工期时，系统先按 `quantity` 运行完整目标函数；若当前资源可排程但业务目标未满足，新增资源分支的搜索范围为 `[quantity, max_quantity]`，推荐数量必须位于默认投入数量和最大上限之间。

固定工期求资源时，系统先按 `max_quantity` 运行硬里程碑和固定工期窗口快速预检。若最大资源快速预检不可行，结果状态为 `max_resources_target_failed`，页面提示“当前最大资源不满足目标”，并尽量展示关键路径晚点 / 超期天数。若最大资源预检 `UNKNOWN` 或单次 15 秒预算耗尽，结果状态为 `unconfirmed`，页面提示“限时内无法确认”。

### 2.3 资源日历字段

资源日历对应 `ResourceCalendar`。本期只读使用默认连续自然日。

| 字段 | 类型 | 必填 | 本期规则 |
| --- | --- | --- | --- |
| `id` | string | 是 | 默认值为 `continuous` |
| `name` | string | 是 | 默认展示含义为连续自然日 |
| `working_weekdays` | number[] | 是 | 默认包含周一至周日 |
| `blackout_dates` | date[] | 否 | 本期默认为空 |

### 2.4 资源模式和数量规则

| 配置项 | 页面标签 | 业务含义 | 规则 |
| --- | --- | --- | --- |
| `quantity` | 默认投入数量 | 当前固定资源测算时实际投入的资源数量 | 非负整数 |
| `max_quantity` | 可增配上限数量 | 固定工期测算时允许系统推荐的资源数量上限 | 非负整数，且大于等于默认投入数量 |
| `enabled` | 启用 | 是否将该资源池作为受限资源参与任务候选和求解约束 | 关闭后停止展开命名资源 |
| `resource_mode` | 受限资源 | 资源按数量形成容量约束 | 本期固定为受限资源 |
| `parallel_rule_description` | 并行施工说明 | 解释同结构同工艺任务是否可在该资源池内并行 | 本期只读展示 |

## 3. 默认数据初始化

### 3.1 初始化原则

系统应提供资源模板，并在项目首次进入排程配置或创建排程方案时，将资源模板初始化为项目级资源配置。初始化后的资源配置属于当前项目或当前方案，用户修改后应持久化到项目级配置，系统模板和其他项目保持独立。

如果项目已有保存过的资源配置，应优先加载项目级配置；如果没有项目级配置，则使用系统模板初始化。

### 3.2 当前默认资源池清单

当前桥梁排程模板至少应包含以下默认资源池：

| 资源池 ID | 资源类型 | 页面名称 | 默认投入数量 | 可增配上限数量 | 同结构同工艺并行规则 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| `pool-rotary-drill` | `rotary_drill` | 旋挖钻 | 1 | 10 | 机械桩基墩组规则 | 桩基旋挖钻施工资源 |
| `pool-circulation-drill` | `circulation_drill` | 回旋钻 | 1 | 10 | 机械桩基墩组规则 | 桩基回旋钻施工资源 |
| `pool-impact-drill` | `impact_drill` | 冲击钻 | 1 | 10 | 机械桩基墩组规则 | 桩基冲击钻施工资源 |
| `pool-manual-pile` | `manual_pile_team` | 人工挖孔班组 | 1 | 10 | 单桩独立管理 | 人工挖孔施工班组 |
| `pool-cap` | `cap_team` | 承台模板 | 1 | 10 | 普通资源互斥 | 承台施工模板或班组资源 |
| `pool-pier-body` | `pier_body_team` | 墩柱模板 | 1 | 10 | 普通资源互斥 | 墩柱施工模板或班组资源 |
| `pool-cap-beam` | `cap_beam_team` | 盖梁模板 | 1 | 10 | 普通资源互斥 | 盖梁施工模板或班组资源 |
| `pool-cast-in-place-continuous-beam` | `cast_in_place_continuous_beam_team` | 连续梁班组 | 1 | 10 | 连续梁联级占用 | 连续梁施工班组 |

### 3.2.1 桩基机械资源专项说明

旋挖钻、回旋钻和冲击钻采用机械桩基墩组规则。当前实现由排程算法自动识别机械桩基墩组：

- 识别范围：同幅别、同墩号、同施工工艺、同结构类型。
- 适用工艺：旋挖钻、回旋钻、冲击钻等机械类桩基工艺。
- 硬规则：同一个墩号下、同一个施工工艺、同一结构类型的机械桩基任务分配给同一台兼容机械钻机。
- 内部排序：同一墩组内桩基任务按桩号或系统桩序从小到大施工。
- 弱目标：不同墩组之间的钻机路径尽量同幅、邻近、少切换；该偏好进入资源路径连续性目标或诊断。
- 人工挖孔班组：按单桩独立任务管理，每个桩基独立分配普通班组资源。

页面只读展示的并行施工说明使用上述业务解释。

### 3.3 数据归属

资源配置分为三层：

- 系统模板：由平台维护，用于新项目或新方案初始化。
- 项目级配置：由项目用户维护，作为项目排程配置默认值。
- 方案级配置：当系统支持多排程方案时，可在项目级配置基础上复制形成方案独立资源配置。

页面编辑作用于当前项目或当前方案。

## 4. 页面功能交互

### 4.1 进入页面

用户进入资源配置页面时，前端应读取当前项目或当前方案的资源池配置，并按后端返回顺序展示。页面标题为“资源配置约束”，副标题说明本期配置默认投入数量 / 可增配上限数量，资源参与容量约束，资源日历按默认连续自然日处理。

当资源配置为空时，系统应展示空态或提示初始化失败，并引导用户初始化资源配置。

### 4.2 查看资源池

每个资源池以卡片形式展示：

- 资源名称。
- 资源类型编码。
- 并行施工说明。
- 默认投入数量输入框。
- 可增配上限数量输入框。
- 启用复选框或开关。

资源名称和资源类型编码为只读信息。资源卡片应适配桌面端和移动端，确保名称、编码、数量输入和启用状态清晰展示。

### 4.3 编辑默认投入数量

用户可编辑默认投入数量。

规则：

- 输入类型为数字。
- 最小值为 0。
- 保存为非负整数。
- 如果输入为空、非法字符或负数，系统应在前端修正或提示。
- 当默认投入数量被调高且超过可增配上限数量时，系统应自动将可增配上限数量同步调高到新的默认投入数量。

默认投入数量影响固定资源求最短工期模式下展开的命名资源数量。

### 4.4 编辑可增配上限数量

用户可编辑可增配上限数量。

规则：

- 输入类型为数字。
- 最小值为当前默认投入数量。
- 保存为非负整数。
- 如果用户输入小于默认投入数量，系统应自动修正为默认投入数量，或明确提示并阻止保存。

可增配上限数量影响固定工期求最少资源模式下可选资源上限。

### 4.5 编辑启用状态

用户可切换资源池启用状态。

规则：

- 启用时，该资源池可按数量展开命名资源，并参与任务候选资源匹配和求解约束。
- 关闭时，该资源池停止展开命名资源。
- 关闭资源池时，相关任务按资源默认充足处理，并在任务图诊断中提示。
- 关闭关键资源池后，用户仍可生成任务图，但应能看到明确 warning。

### 4.6 保存和刷新

实际工程版本应支持项目级资源配置保存能力。保存成功后，用户再次进入同一项目或方案时应看到上次保存的资源配置。

如果当前阶段仍采用统一场景保存或随生成 / 求解提交，PRD 中的产品目标仍应按工程化保存能力实现：前端负责提交标准资源配置，后端负责校验、标准化、持久化和返回最新配置。

### 4.7 操作状态

在资源配置查询、保存、生成任务图或求解过程中，页面应避免产生不一致状态：

- 保存中或生成 / 求解中，资源输入控件应禁用或避免重复提交。
- 保存失败时，应保留用户当前输入，并提示失败原因。
- 资源配置修改后，应提示或标记需要重新生成任务图 / 重新求解。

## 5. 前后端接口能力

### 5.1 查询能力

后端应提供查询当前项目或当前方案资源配置的能力。查询结果应包含资源池列表和默认资源日历。

查询时后端应完成以下处理：

- 如果项目已有资源配置，返回项目级或方案级配置。
- 如果项目没有资源配置，从系统资源模板初始化。
- 返回标准化后的 `ResourcePool[]` 和 `ResourceCalendar[]`。
- 保证受限资源池的可增配上限数量大于等于默认投入数量。

### 5.2 保存能力

后端应提供保存当前项目资源配置的能力。保存时应校验：

- 资源池 ID 稳定且可识别。
- 默认投入数量和可增配上限数量为非负整数。
- 可增配上限数量大于等于默认投入数量。
- 日历引用存在；缺失时按默认连续自然日处理并返回 warning。
- 成本字段按兼容字段保留，当前页面保存校验围绕容量字段执行。

保存成功后，后端返回标准化后的资源配置，前端使用返回值刷新页面状态。

### 5.3 初始化和重置能力

实际工程版本可提供从系统模板重新初始化或重置项目资源配置的能力。该能力作为可选后台能力预留，后端设计应支持系统模板与项目级配置分离。

## 6. 联动规则

### 6.1 上游输入

资源配置依赖以下上游数据：

- 系统资源模板或项目级资源配置。
- 工艺工效库中的默认资源类型。
- 项目结构参数和任务工艺选择结果。
- 默认资源日历。

工艺工效库决定任务需要哪类资源，资源配置决定该类资源是否作为受限资源参与排程。

### 6.2 任务候选资源匹配

任务生成时，系统按工艺和构件类型匹配资源池：

- 桩基按施工工艺匹配旋挖钻、回旋钻、冲击钻或人工挖孔班组。
- 承台匹配承台模板。
- 墩柱匹配墩柱模板。
- 盖梁匹配盖梁模板。
- 现浇连续梁匹配连续梁班组。

当匹配到启用且可用上限大于 0 的受限资源池时，任务记录该资源类型作为候选资源。匹配失败时，任务输出资源诊断。

### 6.3 命名资源展开

系统根据资源池展开命名资源：

- 固定资源求最短工期时，使用 `quantity`。
- 固定工期求最少资源时，使用 `max_quantity`。
- 关闭的资源池停止展开。
- 数量为 0 的资源池跳过展开，并输出 warning。

命名资源名称应便于用户理解，例如“旋挖钻1”“旋挖钻2”。

命名资源应继承资源池上的 `same_structure_resource_binding` 和 `parallel_rule_description`，供求解器和结果诊断使用。后端兼容读取额外字段时，求解并行边界以当前 `ResourcePool` 规则和机械钻机墩组规则为准。

### 6.4 求解影响

求解器应对每个命名资源建立不可重叠约束，确保同一资源同一时间只能执行一个任务。同时，求解器应读取仍保留的同结构同工艺绑定规则：

- 当 `same_structure_resource_binding=true` 时，同一结构物、同一构件类型、同一工艺的任务应绑定到同一命名资源。
- 同结构同工艺资源绑定由 `same_structure_resource_binding` 控制。
- 机械钻机桩基墩组规则按独立算法口径处理。

资源配置影响：

- 任务候选资源是否存在。
- 命名资源数量。
- 同结构同工艺任务是否可由多个资源并行施工。
- 固定资源模式下的最短工期。
- 固定工期模式下的最少资源推荐数量。
- 资源分配明细和资源连续性诊断。

### 6.5 结果失效

以下资源配置变更会影响任务图或求解结果：

- 修改默认投入数量。
- 修改可增配上限数量。
- 修改启用状态。
- 后续版本中修改并行施工规则字段。
- 后续版本中修改资源日历或资源工艺映射。

发生上述变更后，已有任务图、求解结果和方案对比结果标记为失效。系统应要求用户重新生成任务图或重新求解。

## 7. 校验与异常处理

### 7.1 前端校验

前端应至少保证：

- 默认投入数量大于等于 0。
- 可增配上限数量大于等于 0。
- 可增配上限数量大于等于默认投入数量。
- 数量字段保存为整数。
- 修改默认投入数量后，可增配上限数量自动保持大于等于默认投入数量。
### 7.2 后端校验

后端应至少保证：

- `resource_pools` 可为空时要有明确业务含义；默认情况下应至少返回系统模板资源池。
- 受限资源池的 `quantity`、`max_quantity` 非负。
- 受限资源池的 `max_quantity >= quantity`。
- 额外兼容字段按只读兼容处理，求解并行边界以当前资源规则为准。
- 关闭的资源池停止展开命名资源。
- 引用缺失的资源日历时，返回 warning 并按连续自然日处理。

### 7.3 异常提示

| 场景 | 产品提示 |
| --- | --- |
| 默认投入数量非法 | 默认投入数量必须为非负整数 |
| 可增配上限数量非法 | 可增配上限数量必须为非负整数，且大于等于默认投入数量 |

严重错误应阻止保存；提醒类问题允许继续生成任务图或求解，但需要在诊断中明确展示。

## 8. 验收标准

### 8.1 页面展示验收

- 用户进入资源配置页面后，能看到当前项目或方案的资源池清单。
- 每个资源池展示资源名称、资源类型编码、默认投入数量、可增配上限数量、启用状态和并行施工说明。
- 页面展示系统维护的资源池清单。
- 并行施工说明为只读展示。
- 资源名称和资源类型编码为只读展示。
- 页面说明中明确资源日历本期按默认连续自然日处理。

### 8.2 数量编辑验收

- 用户可修改默认投入数量，保存后再次进入页面仍能看到修改后的值。
- 用户可修改可增配上限数量，保存后再次进入页面仍能看到修改后的值。
- 默认投入数量输入负数时，系统自动修正或提示，并保存为非负值。
- 可增配上限数量输入小于默认投入数量时，系统自动修正为默认投入数量，或提示并阻止保存。
- 默认投入数量调高超过可增配上限数量时，可增配上限数量自动同步调高。

### 8.3 启用状态验收

- 用户可关闭资源池，保存后再次进入页面仍保持关闭状态。
- 关闭资源池后重新生成任务图，该资源池停止展开命名资源。
- 关闭资源池后，相关任务按资源默认充足处理，并产生明确 warning。
- 再次启用资源池并设置数量大于 0 后，重新生成任务图可看到对应命名资源。

### 8.4 排程联动验收

- 固定资源求最短工期时，系统使用默认投入数量展开资源。
- 固定工期求最少资源时，系统使用可增配上限数量作为资源可选上限。
- 最少资源推荐数量在对应资源池可增配上限内。
- 修改资源配置后，已有任务图、求解结果和方案对比结果失效。
- 重新生成任务图后，任务资源候选与当前资源配置一致。
- 重新求解时，系统按资源池配置执行同结构同工艺资源绑定，并按“幅别 + 墩号 + 工艺 + 结构类型”的机械钻机墩组规则处理桩基机械资源。

### 8.5 默认数据验收

- 新项目或新方案首次进入资源配置页面时，系统可按资源模板初始化默认资源池。
- 当前桥梁资源模板至少包含旋挖钻、回旋钻、冲击钻、人工挖孔班组、承台模板、墩柱模板、盖梁模板和连续梁班组。
- 旋挖钻、回旋钻和冲击钻默认按“幅别 + 墩号 + 工艺 + 结构类型”的机械桩基墩组规则处理。
- 人工挖孔班组默认按单桩独立任务处理。
- 项目级资源配置修改后，系统模板和其他项目配置保持独立。

## 9. 后续扩展建议

以下能力作为预留扩展，建议在数据结构和权限设计上保留扩展位：

- 资源日历编辑，包括工作星期、停工日期、班次和节假日模板。
- 资源池新增、删除、停用和排序。
- 工艺与资源池映射编辑。
- 单台设备和班组明细管理。
- 资源成本属性和资源成本优化排程。
- 跨项目资源共享、资源调拨审批和资源占用看板。
- 资源配置版本管理、复制方案和恢复默认模板。
